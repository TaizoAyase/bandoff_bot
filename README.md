# bandoff の使い方

スタジオオフ会で「どの曲を、誰が、どのパートで弾くか」を決めるための Web アプリです。
アカウント登録はいりません。主催者が Discord に貼った URL と合言葉で入ります。

## 主催者

1. トップページの「イベントを作る」から、イベント情報・自分の表示名・持ち込み楽器・
   合言葉を入力して作成する
2. 作成後に出る **主催者キー** と **引き継ぎコード** をメモする
3. 「Discordに貼る文面」(URL と合言葉)をコピーして Discord に投稿する

「主催者設定」では、イベント情報の編集、募集の締め切り、主催者キー・合言葉の再表示、
JSON でのエクスポートができます。主催者は曲一覧で他の人を枠に入れたり辞退させたり、
「参加者一覧」から参加者を外したりもできます。

別の端末から主催者として操作するときは、曲一覧の「主催者ログイン」で主催者キーを
入力します。主催者キーを渡せば、複数人が主催者になれます。

## 参加者

### はじめて入る

1. Discord の URL を開き、合言葉を入力する。曲を見るだけなら登録はいりません
2. 入りたい枠の「+ 参加」を押し、表示名と持ち込み楽器を登録する。登録が済むと、
   そのまま押した枠に入ります
3. 表示される **引き継ぎコード** をメモする

2回目からは URL を開くだけで、自分として入れます。

### 曲を追加する

「曲を追加」から、曲名・アーティスト・キー・参考URL・譜面URL(10件まで)・備考と
パート構成(最初は Gt / Gt / Ba / Dr / Vo)を入力します。追加しただけでは自分は
枠に入らないので、弾く枠の「+ 参加」を押してください。

### よく使う操作

| やりたいこと | 操作 |
|---|---|
| 楽器を変える | 今の枠で「辞退」して、別の枠で「+ 参加」 |
| 辞退する | 「辞退」。枠は空いたまま残り、他の人が入れます |
| 枠を足す・消す | 「+ 枠を追加」/ 空き枠の「削除」。どの曲でも誰でもできます |
| 同じ曲をもう一度やる | 曲カード下の「2回目を追加」(2回目以降は「3回目を追加」…) |
| 曲情報を直す | 「曲を編集」。参加登録した人なら誰でもできます |
| 曲を消す | 自分が追加した曲で、まだ誰も枠に入っていないときだけできます |
| 参加をやめる | 「設定」→「参加を取りやめる」(主催者はできません)。入っていた枠はすべて辞退になります |

募集が締め切られたあとは、主催者以外は書き込めません。

### 当日

- 「自分のエントリー」で、担当する曲とパートを確認する
- 「参加者一覧」で、みんなの持ち込み機材を確認する

### 端末を変えた・ブラウザのデータが消えた

合言葉を入れ直してから、「引き継ぎコードで入る」(「設定」→「引き継ぎコードで
引き継ぐ」でも同じ)に引き継ぎコードを入力します。引き継ぎコードは「設定」で
再表示できますが、今の端末が使えるうちに限ります。

## Discord のコマンド

主催者が「Discord の /bandoff コマンドから開けるようにする」をオンにしたイベントで
使えます。

- `/bandoff list` 開けるイベントの一覧を出す(自分にだけ見えます)
- `/bandoff open` 合言葉なしでイベントに入る。初回は参加登録(登録済みの人は
  紐付けの確認)をすると、次回からそのまま自分として入れます
- `/bandoff new` イベント作成ページへのリンクを出す

`/bandoff open` のリンクは10分間・1回だけ有効です。他の人に渡さないでください。
Discord から入っても主催者にはなりません。主催者画面は「主催者ログイン」から入ります。
開催から24時間たつと、これらのコマンドでは入れなくなります。そのときは URL と
合言葉で入ってください。

## 知っておいてほしいこと

- エントリー・辞退・曲の追加や編集などは、Discord の通知チャンネルに流れます。
  URL・合言葉・引き継ぎコードは流れません
- 同じ回で2つの枠に入ると警告が出ます(Gt とコーラスのように両立できるなら、
  そのまま確定できます)
- 本人確認は「身内の集まり」が前提です。URL・合言葉・各種キーを外に出さないで
  ください
